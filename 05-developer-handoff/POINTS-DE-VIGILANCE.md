# Points de vigilance et limites

1. **Archive Webflow ≠ CMS fonctionnel.** L’écran d’export indique explicitement que les fonctionnalités CMS et les formulaires natifs ne sont pas inclus. Les données ont donc été exportées séparément. La recherche hébergée, les traitements de formulaires, les éventuels services e-commerce et les backends doivent être maintenus ou remplacés lors d’une implémentation.
2. **Designer et publication sont deux états distincts.** Les deux ZIP et les réponses publiques sont conservés sans fusion. Certains contenus courants du CMS peuvent être des brouillons ou différer de la dernière publication.
3. **Le total CMS est vérifié.** Les 78 CSV comprennent 2 367 lignes localisées, exactement le total du compte lors de la collecte. Cela vérifie l’inventaire exporté à cet instant, pas l’exécution de chaque route ni la validité de chaque relation dans le futur CMS.
4. **Un asset ne répond pas.** `https://cdn.prod.website-files.com/plugins/Basic/assets/placeholder.60f9b1840c.svg` renvoie HTTP 403. C’est un placeholder générique Webflow. Aucun visuel de remplacement n’a été inventé. Le rapport des téléchargements distingue ce manque des anciennes erreurs de parsing d’URL CSS qui ont été résolues.
5. **Ressources ≠ sauvegarde de tout le compte.** Les ressources natives, publiées et référencées par le CMS sont archivées lorsqu’elles étaient accessibles. Les réglages affichent 11,798 GiB de stockage incluant fichiers, polices et sauvegardes. Ce dossier n’est pas un export de l’ensemble des sauvegardes historiques, variantes non référencées ou binaires internes Webflow.
6. **Les HTML publics gardent leurs liens d’origine.** Les fichiers bruts peuvent charger les CDN et trackers de production quand on les ouvre ou les sert. Le dossier n’est pas un site hors ligne dont les liens ont été réécrits. Les manifestes donnent les correspondances URL → fichier local pour le développeur.
7. **Compteurs marketing.** Dans le script observé, les valeurs 482 871 € et 2 912 boutiques sont codées dans l’animation CountUp, avec des valeurs de départ distinctes. Cette collecte ne les valide pas comme des indicateurs calculés en temps réel.
8. **Tracking à vérifier.** Plusieurs pixels et outils coexistent ; les identifiants GTM de script et de `noscript` diffèrent dans les sources. Leur configuration et le consentement doivent être validés avant toute future publication. Aucun compte analytics n’a été migré.
9. **Dépendances externes.** Outils gratuits, YouTube/Embedly, liens Shopify, liens de l’application et services externes ne deviennent pas autonomes par copie du HTML. Leurs URL sont inventoriées ; leurs backends ne sont pas inclus.
10. **Pas d’historique de prospects ni de secrets de compte.** Les schémas de formulaires présents dans les pages sont inventoriés. Les 478 soumissions annoncées par Webflow n’ont pas été exportées : elles ne sont pas nécessaires pour reconstruire le site. Aucun jeton privé Webflow, accès d’équipe, mot de passe ou compte de facturation n’a été créé ou transmis.
11. **Référence visuelle partielle.** Les captures de l’accueil anglais sont prises dans l’état initial, sans défilement déclenchant toutes les animations. Les sources originales et les assets font foi pour les sections absentes des captures. Aucun audit visuel mobile exhaustif n’est revendiqué.
12. **Aucune implémentation.** Les dossiers de contexte CodePen, React et Next.js sont des consignes de migration. Il n’existe ici ni starter généré, ni nouvelle app, ni modification du dépôt Copyfy.
