# Outils de collecte utilisés

Ces scripts ont servi uniquement à télécharger, inventorier et convertir les données de l’export. Ce ne sont pas des fichiers d’application ni une implémentation de la copie du site. Ils ont été déplacés ici après la collecte : leurs chemins relatifs initiaux ne constituent pas une interface de relance supportée. Les manifestes, CSV, JSON, sources et documents du dossier sont la livraison exploitable.
