# Publication publique

Cette copie contient tous les chemins de fichiers de la collecte locale. Pour respecter les consignes de confidentialité, les liens de contact nominatifs, identifiants personnels textuels et chemins locaux nominatifs ont été masqués. Les deux ZIP ont également été retraités ; leurs empreintes publiques diffèrent donc des originaux privés. Les données métier, médias et structures restent disponibles.

Les originaux locaux sont conservés séparément. Les manifestes de taille et d’intégrité ont été recalculés sur la copie publique. Les inventaires et captures décrivent la collecte historique ; ils ne constituent pas un site déployé ni une réimplémentation.

Aucun jeton de connexion privé, aucune soumission de prospect et aucun compte de suivi ne sont publiés. Les identifiants de pixels publics et le code client du site restent présents en tant que sources de migration.

Voir PUBLICATION-REDACTIONS.json pour la liste des fichiers concernés, sans les valeurs masquées.
