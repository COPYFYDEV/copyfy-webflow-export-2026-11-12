[FILES.json](FILES.json) et les segments du dossier `file-index/` répertorient chaque fichier de données avec sa taille, son SHA-256 et son URL directe. Les originaux locaux restent séparés ; voir [les notes de publication](PUBLICATION-NOTES.md) pour les masquages de confidentialité de cette copie.

Les HTML et JavaScript bruts conservent les dépendances et trackers d’origine. Le dépôt est une archive de référence, pas un site hébergé ni une garantie de parité fonctionnelle. Un placeholder SVG Webflow inaccessible est documenté.
